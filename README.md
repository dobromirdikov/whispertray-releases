# WhisperTray releases

Installers and the update feed for **WhisperTray**, offline voice-to-text for Windows.

- Download the latest version: [Releases](https://github.com/dobromirdikov/whispertray-releases/releases/latest)
- Product page: https://dobromirdikov.com/whispertray/

The app checks `releases/latest/download/appcast.xml` for updates. Installers are EV code-signed by Minty Analyst Ltd., and each update in the feed carries an EdDSA signature that the app verifies before installing.

The source code is not in this repository.
